## Itens básicos da configuração 💎

Os itens básicos que devem ser satisfeitos para que a configuração disponibilizada neste repositório funcione corretamente na sua máquina são:

 1. Possuir o [Neovim](https://neovim.io) instalado (isso é meio que óbvio 🧐).
 2. Possuir o [vim-plug](https://github.com/junegunn/vim-plug) manager, instalado!
 3. Ter pelo menos uma [Nerd font](https://www.nerdfonts.com/) instalada, particularmente recomendo a [Hack Nerd Font](https://www.nerdfonts.com/font-downloads#:~:text=Hack).
 4. O _software_ de versionamento [Git](https://git-scm.com/downloads).
 5. O _software_ [bat](https://github.com/sharkdp/bat).
 6. O _software_ de busca _fuzzy_  [fzf](https://github.com/junegunn/fzf).
 7. O _software_ de busca recursiva em diretórios [ripgrep](https://github.com/BurntSushi/ripgrep).
 8. O servidor de desenvolvimento [Live Server](https://www.github.com/tapio/live-server).
 9. Os servidores de linguagem [Bash Language Server](https://github.com/bash-lsp/bash-language-server), [clangd](https://clangd.llvm.org/), [LuaLS](https://github.com/LuaLS/lua-language-server), [ocamllsp](https://github.com/ocaml/ocaml-lsp), [texlab](https://github.com/latex-lsp/texlab) e [lsp_server](https://github.com/jamesnvc/lsp_server).
 10. O [NPM](https://www.npmjs.com) para instalar as extensões do [Coc.nvim](https://www.github.com/neoclide/coc.nvim).
